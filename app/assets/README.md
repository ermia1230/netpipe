# Assets Placeholder

The app expects the following asset files in this directory:

- `icon.png` - App icon (1024x1024)
- `splash.png` - Splash screen (1242x2436)
- `adaptive-icon.png` - Android adaptive icon (1024x1024)
- `favicon.png` - Web favicon (48x48)

For now, Expo will use default placeholders. You can add custom assets later.

## Creating Assets

You can create simple assets using:
- Canva (https://canva.com)
- Figma (https://figma.com)
- Or any image editor

Or use Expo's asset generator:
https://docs.expo.dev/develop/user-interface/app-icons/
